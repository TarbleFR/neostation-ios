# RiiSU / iiSU System Art Attribution

NeoStation iOS exposes RiiSU as a curated **external, on-demand** System Art
pack. The RiiSU artwork is not bundled into the NeoStation IPA.

Sources and credits:

- RiiSU for NeoStation — https://github.com/mult1v4c/RiiSU
- RiiSU maintainer/repository owner — https://github.com/mult1v4c
- iiSU Interpreted for ES-DE — https://github.com/VictorUnlocked/iisu-interpreted-es-de
- iiSU Network — https://iisu.network/

RiiSU's README thanks iiSU Interpreted for providing the system art icons and
iiSU Network for the original inspiration. Its sample theme metadata identifies
the author as **iiSU Network**.

No standalone license file was visible in the RiiSU repository when this
integration was added. NeoStation therefore keeps the artwork hosted by the
original project and downloads/cache it only when the user selects the pack.

rights that the upstream project has not published.
